# DannyBoy 俄罗斯方块

一款适合电脑和手机浏览器的原创经典俄罗斯方块小游戏，包含公开班级排行榜。

## 游戏方式

- 电脑：方向键移动和旋转，空格快速落下，C 暂存方块，P 暂停。
- 手机：使用屏幕下方的方向、旋转、落下和暂存按钮。
- 首次进入输入昵称，无需注册。每台设备保留昵称和本机最高分。
- 游戏结束后自动提交成绩，排行榜展示每位玩家的最高成绩。

## 发布结构

- `github-pages/`：GitHub Pages 直接发布的静态游戏。
- `app/` 与 `app/api/scores/`：游戏页面和排行榜数据接口。
- `db/`、`drizzle/`：排行榜数据库结构与迁移。

项目不使用广告、统计或追踪服务。
